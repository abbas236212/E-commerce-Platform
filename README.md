E-commerce Platform Database (DBMS Project)

This project is a fully normalized relational database for a multi-vendor e-commerce platform using SQL (Oracle/MySQL-compatible). It manages customers, vendors, products, carts, orders, payments, shipments, reviews, and discounts.

The database is designed in Third Normal Form (3NF) with primary keys, foreign keys, and constraints to ensure data integrity. Sample data and SQL queries demonstrate joins, subqueries, aggregations, and reporting.
